# Isolated Lab

Used for controlled ransomware-style, malware-style and phishing-style scenarios and as the fallback dataset source.

Rules:

- Host-only or internal virtual network, no internet-connected or production systems.
- Owned or authorised VMs only. Snapshot before every scenario.
- Benign simulations or controlled test artefacts only.
- Agent actions limited to pre-approved, reversible, sandboxed ones, with human confirmation.

Planned contents: VM setup notes, scenario scripts (benign simulators), capture and labelling procedure.
