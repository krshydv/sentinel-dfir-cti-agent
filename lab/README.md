# Isolated Lab

Used for controlled ransomware-style, malware-style and phishing-style scenarios and as the fallback dataset source.

Rules:

- Host-only or internal virtual network, no internet-connected or production systems.
- Owned or authorised VMs only. Snapshot before every scenario.
- Benign simulations or controlled test artefacts only.
- Agent actions limited to pre-approved, reversible, sandboxed ones, with human confirmation.

Simulated scenarios (port scan, SSH brute force, exfiltration) are generated by `scripts/simulate_lab.py` into `data/lab/conn.log` with `ground_truth.csv`, and analysed end to end by `scripts/analyze_lab.py`. Real Zeek logs from lab VMs can be analysed the same way by pointing `--input` at the log or folder.

Planned contents: VM setup notes and the capture and labelling procedure for real lab traffic.
